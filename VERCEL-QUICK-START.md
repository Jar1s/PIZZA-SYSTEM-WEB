# ⚡ Vercel Quick Start - Frontend

Rýchly guide na nasadenie frontendu na Vercel.

## 🚀 3 Jednoduché Kroky

### 1. Prihlás sa do Vercel
- Choď na [vercel.com](https://vercel.com)
- Prihlás sa cez GitHub

### 2. Import Projektu
- Klikni **"Add New..."** → **"Project"**
- Vyber repository: `PIZZA-SYSTEM-WEB`
- **DÔLEŽITÉ:** Nastav **Root Directory** na `frontend`

### 3. Nastav Environment Variables
V **Settings → Environment Variables** pridaj:

```
NEXT_PUBLIC_API_URL=https://pizza-system-web.onrender.com
```

### 4. Deploy!
- Klikni **"Deploy"**
- Počkaj ~2-5 minút
- Hotovo! 🎉

## ✅ Testovanie

Po deploymente testuj:
- `https://your-project.vercel.app?tenant=pornopizza`
- `https://your-project.vercel.app?tenant=pizzavnudzi`
